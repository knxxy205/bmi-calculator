# ProFit - Kalkulator BMI & Makro Nutrisi

Aplikasi web kesehatan modern untuk menghitung Indeks Massa Tubuh (BMI), Total Kebutuhan Kalori Harian (TDEE), dan estimasi asupan Makro Nutrisi harian berdasarkan tingkat aktivitas fisik.

🌍 **Live Demo:** [ProFit - Kalkulator BMI](https://knxxy205.github.io/bmi-calculator/)

## ✨ Fitur Utama
- **Penilaian BMI:** Mengukur status berat badan dengan indikator warna visual dan *progress bar*.
- **Kalkulasi TDEE:** Menghitung total kalori harian yang terbakar (berdasarkan rumus *Mifflin-St Jeor*).
- **Distribusi Makro Nutrisi:** Rekomendasi pembagian nutrisi harian (Protein 30%, Karbohidrat 40%, Lemak 30%).
- **Rekomendasi Ahli:** Panduan otomatis mengenai defisit/surplus kalori dan jenis latihan yang cocok.
- **Desain Premium:** Dark mode UI dengan aksen *slate/blue*, *glassmorphism*, dan transisi *smooth scroll*.

## 🛠️ Tech Stack
- **HTML5 & CSS3**
- **JavaScript (Vanilla JS)** untuk manipulasi DOM dan logika matematis.
- **Tailwind CSS v3 (CDN)** untuk utility-first styling.

## 🚀 Instalasi & Menjalankan Lokal
Proyek ini sepenuhnya bersifat statis (client-side) tanpa *build-step* atau *backend*.

1. Clone repositori ini ke lokal:
```bash
git clone https://github.com/knxxy205/bmi-calculator.git
```
2. Buka file `index.html` langsung di *browser* pilihan Anda, atau gunakan ekstensi seperti **Live Server** di VS Code.
